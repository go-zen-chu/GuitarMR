    サンプル曲

    パブリックドメインの曲です。「開く」でスキャンから読み取りまでを、「演奏ビュー」でコードと TAB をテンポに合わせて音で確かめられます。

      手書きTAB譜をデータにする

      スキャンしたPDFか、楽譜を撮った写真を選ぶと、ページの向きと傾きを直し、段と小節をこの端末の中で見つけます。写真は白い紙の部分を切り出して、斜めから撮った歪みと明るさのムラを直してから使います。続けて Claude にコードと構成（リピートや記号）を読ませ、小節をタップして確認・修正できます。

      写真は1枚が1ページです。紙より暗い机などに置き、紙全体が入るように撮ってください。ファイルを選ぶ画面が開かないときは、このリンクを Safari や Chrome で開いてください（Claude アプリの中では選べないことがあります）。パソコンでは PDF や写真をこのページにドラッグしても読み込めます。

        段（五線＋TAB）小節（番号は通し）

        前回の作業（この端末のライブラリに残っていた内容）を開きました。

        Claude で読む（コード・構成・TAB）

        各段の画像（写真は補正したもの）を、あなたの Claude（claude.ai のアカウント、Android アプリでは自分の API キー）に送って読ませます（1ページ数十秒）。PDFや写真そのものは送りません。

        コードと構成を読み終えたら、TAB の数字とリズムも読めます。拍の合計やフレットの範囲を確かめ、おかしい小節は要確認にします。

        読み取りのメモ

          リピートと番カッコの対応、D.S. / Coda の飛び先、セクション、各小節の拍の合計と押さえられるかを確かめています。タップするとその小節を開きます。

            中身を見る（gts JSON）

              設定

              Claude API キー

              読み取りに使う自分の API キーを変えたり、この端末から消したりします。

              この端末のライブラリ

              開いた PDF・写真と作業中の内容は、この端末のブラウザの中にだけ保存されます（サーバーには送りません）。もう一度開くと、保存したファイルから解析し直して続きから作業できます。ブラウザのデータを消すと消えるので、仕上がったら gts.json も保存してください。

              別の端末へ引っ越す（書き出し・取り込み）

              ライブラリ全体を1つのファイルに書き出し、新しい端末で取り込みます。作業内容（軽いデータ）を先に、PDF・写真を最後に書き出すので、途中で切れたり一部が壊れたりしても作業内容は移せます。

              gts.json を演奏ビューで開く

              ほかの端末で保存した gts.json だけで、PDF や写真なしに演奏ビューで開けます。

              GuitarMR · layout（小節の位置）は端末内で、structure と chords（構成とコード）は Claude で読みます。TAB の数字と歌詞の読み取りはこれからです。開いたファイルと作業中の内容は、この端末のブラウザの中にだけ残ります。
              楽譜 スキャン

              スペース区切り。拍の位置を指定するときは @ を付けます: C G/B@2.5

              1音ずつ 長さ:内容 をスペース区切り。長さ 4=4分 8=8分（. 付点、t 3連）、内容 弦-フレット（+ で同時、x ミュート）、r 休符、/ ストローク。後ろに !d ダウン !u アップ。例: 8:6-0+4-2!d 8:r 4:/ 8t:1-0 8t:1-2h 8t:1-3
